# YLILA VILLAGE EVENTS SYSTEM (FOUNDATION)

Design rule: not just fun scenes. Each event deepens relationships, reveals traits, quietly shows systems (skills, stamina, mana, roles), and reinforces what's worth protecting.

## 1. Harvest Festival (CORE EVENT)

Theme: gratitude, abundance, community.

Key moments: lantern lighting at sunset, shared feast (Marie shines here), kids running around freely, storytelling from elders.

Highlight: Chief Edward performs as a bard — lute or simple guitar equivalent. Sings stories of past heroes, warnings disguised as songs, encouragement. Defines Edward's dual role: leader + mood stabilizer (future combat tie-in). Tone: not constant poetry, but intentional lines. "Strong hands build the land— but steady hearts keep it standing."

Orange moment: sees everyone happy, feels warmth… but also responsibility. First quiet thought: "I want to protect this."

## 2. Fishing Day (Amy Focus)

Theme: patience, bonding, subtle skill.

Key moments: Steve teaches knife handling (safe, practical), Amy showing off (and failing sometimes), Orange relaxing (rare moment). (Note: "Carl" was Steve's early name — Steve locked as Amy's father, Naomi as her mother. "Carl" stays shelved as a spare name.)

System tie-in: precision as early hint of DEX importance, calm focus as mental stability (INT hint).

Character beat: Amy opens up more here — softer side beyond the energetic personality.

Resolved: Steve locked as Amy's father and knife teacher. "Carl" reserved as spare name.

## 3. Blacksmith Day (Leo Focus)

Theme: strength, responsibility, endurance.

Key moments: Ethan repairing tools, Leo tries hammer work, fails → improves → stubborn persistence.

System tie-in: strength vs stamina, weight handling, equipment matters.

Character beat: "If I can't protect it… I'll build something that can."

## 4. Forest Gathering Day (Lyra Focus)

Theme: observation, silence, awareness.

Key moments: herb gathering, Lyra spotting things others don't, first sighting of slimes and horned rabbits.

System tie-in: awareness as behavior not just stats, positioning as early archer instinct.

Character beat: Lyra quietly noticing Orange again. "…You don't get tired."

## 5. Crop Trouble (Mini Conflict Event)

Theme: first responsibility, teamwork.

Scenario: horned rabbits eating crops. Kids try to help, first real coordination, light non-lethal combat.

System tie-in: skill calling in a real scenario, visible stamina drain, Orange holds back healing.

## 6. Rainy Day / Rest Day (VERY IMPORTANT FOR ORANGE)

Theme: emotional rest, reflection.

Key moments: staying indoors, family conversations, silence.

Orange arc: not physical exhaustion — emotional buildup (future setup).

## Bonus Event: Mini Talent Night (Pre-Festival)

Kids perform: Leo → strength show (fails → funny), Amy → sword tricks, Lyra → trick shots, Orange → …nothing (observes). Edward closes the night with a song.

## Why This System Works

Builds attachment, shows growth naturally, introduces systems without info-dump, gives pacing breaks.

Core structure: Peace → Routine → Bonding → Small Problems → Growth. So when invasion happens later… it hurts.
