# Manuscript (Canon Text Only)

Finished novel chapters live here, one file per chapter, organized by
volume. Nothing here is a draft — every file passed the canon pass.

## Pipeline

1. Write raw in `docs/story-draft/` (messy is fine).
2. Canon pass: apply `docs/story-draft/revision-notes.md`, then check:
   - Orange's viewpoint only, no head-hopping
   - Kid-safe: no blood pools, no gore, no self-harm, modest dress
   - System honesty: costs, cooldowns, limits shown; no free power
   - Staging: every scene stands somewhere on the map
   - Continuity: names, places, kits match the bible
3. Graduate the chapter here. Drafts stay where they are as history.

## Naming

`volume-1/chapter-01-the-boy-who-didnt-break.md` — number plus slug.
Volume 2 numbering is volume-scoped (chapters 9–12, 15–18 already used
in drafts); a renumber pass happens before Volume 2 graduates anything.
