# Story Drafts (Non-Canon Holding Folder)

Raw early drafts live here. Nothing in this folder is canon until it is reconciled and locked into the story bible ([README.md](../../README.md) and `docs/`).

Rules for this folder:

- Drafts are raw material, not locks. Locks live in the bible docs.
- When a draft detail gets locked, the lock goes in its bible file, not here.
- Mentor details the author recovers go here first if unsure, then lock into [Mentors](../characters/mentors/mentors.md) once confirmed.
- Never treat a draft line as canon during scene writing unless its lock exists.
