Classes evolve to reflect identity — not just power. Evolution is never automatic. It reflects how the person actually fights and lives: consistent training, specialization, skill mastery, combat experience, personal style.

Volume 1 cap (locked): base classes only. Everyone starts simple — Fighter, Archer, Healer — and earns specialization later. High tiers below are late-world possibilities, not Ylila power levels.

## Acquisition and limits

A class is earned through consistent training in a field, repeated use of related skills, and reaching a level threshold — then verified by a guild exam checking capability, control, and role readiness. The class is recognized, registered, and appears in the Status Window.

Ylila's outpost is small: it can register base classes and post pest, herb, and delivery quests. Evolved-tier exams happen at a full guild (Ember side), which keeps Volume 1 grounded. The exam itself runs skill demonstration, combat evaluation, and a control-and-consistency check — no fake classes, no premature specialization.

Future expansion (confirmed, not Volume 1): subclasses, class awakening, dual-class system at advanced stage only. Stat bias examples: Tank line toward Vitality, Archer toward Dexterity, Mage toward Intelligence.

Limits (locked): one primary class to start. True multi-classing is rare, difficult, requires discipline. No instant mastery, no free switching, no skipped progression.

Correction to the pasted draft: Warden is NOT a base class. Base entries are Fighter, Archer, Mage, Healer (plus Scout as entry to the speed line). Leo starts Fighter and earns Warden later — he does not start as Warden.

A class affects stat growth bias (which stats grow efficiently), skill availability (what unlocks), and combat role (frontline, support, ranged, control). Hybrid skills blend logically — a fighter-mage blend earns something like Flame Blade (STR + INT), not two separate kits stapled together.

## Rules

- New classes can emerge from training style, environment, skill combinations. The world does not need every class defined upfront.
- Pure classes specialize faster. Hybrids are versatile but master slower.
- Rare paths (Sword Saint, Saint/Paladin variants, Arcane Knight) are condition-based: extreme mastery plus rare mentorship.
- Skill Evolution feeds class evolution: HOW you train shapes WHAT the class becomes. Style without discipline evolves nothing.
