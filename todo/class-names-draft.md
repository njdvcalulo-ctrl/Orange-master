viewer. No explanation scenes spent on what a class word means. Locked
identities (Amy's Sword Dancer, Orange's unassigned hybrid, Titan as Leo's
future title) stay untouched.

## Recommendations per line

Physical (offense): Fighter → Warrior → Swordmaster → Royal Knight /
Sword Saint (rare). CHANGE: Knight → Swordmaster, because Knight now belongs
to the tank line. Swordmaster is known from Fire Emblem and wuxia-adjacent
media. Nothing else changes.

Tank (defense): Fighter → Knight → Guardian → Titan. LOCKED this session.

Heavy (power): Fighter → Brawler → Berserker → Warlord. CHANGE: Crusher →
Brawler, Vanguard → Berserker, Warbringer → Warlord. Berserker and Warlord
need no introduction. Old names archived.

Speed: Scout → Hunter → Ranger → Assassin → Shadow. CHANGE: insert Hunter
(most basic bow-word there is), end at Shadow instead of Ghost → Phantom.
Lyra's line becomes Archer → Marksman → Sniper → Starpiercer? NO — keep
Lyra locked as Archer → Sniper → Eagle Eye → Starpiercer; the world line is
Scout → Hunter → Ranger → Assassin → Shadow. Two entry words (Scout,
Archer) is fine: villages say Archer, guilds say Scout.

Magic: Mage → Elementalist → Archmage → Sage (rare). CHANGE: Grand Arcanist
→ Sage. Everyone knows what a Sage is. Element specs: Pyromancer /
Cryomancer / Stormcaller. CHANGE: Flamecaster → Pyromancer, Frostbinder →
Cryomancer. Stormcaller stays (it is already plain). Absolute Zero and
Thunderlord archived as boss-tier titles, not classes.

Hybrid magic: Mage → Battle Mage → Spellblade → Rune Knight (rare). CHANGE:
Sage Knight → Rune Knight, Arcane Champion archived. Rune Knight is known
from half a dozen games. Xavier stays a swordmage in prose; his formal class
can stay unregistered, which fits his humble act.

Support: Healer → Priest → Bishop → Saint. NO CHANGE. Already perfect.

Performance: Bard → Minstrel → Maestro (rare). CHANGE: Songweaver →
Minstrel, War Chanter → archived, Soul Conductor → Maestro. Dancer → Blade
Dancer → Prima (rare). CHANGE: Spirit Dancer → archived, Celestial Performer
→ Prima. Maestro and Prima are everyday words. Edward's Tank-Bard stays a
unique hybrid title. Eli trains Lyra on the Archer line regardless.

Craft and life: keep the plain compounds (Blacksmith → Weaponsmith → Master
Smith; Carpenter, Tailor, Fisher, Merchant). CHANGES: Runeforger → Runesmith;
Farmer → Tiller → Harvest Lord? NO — keep Farmer → Cultivator → Land Keeper
→ Verdant Master, because cultivation readers know Cultivator cold and John
already owns it. Cook → Chef → Master Chef (NEW — Marie owns Chef; gives her
a title to earn on-screen).

Tamer: Tamer → Handler → Beast Master → Beast Lord. CHANGE: Primal Sovereign
→ Beast Lord. Summoner → Conjurer → Warlock (rare). CHANGE: Spirit Caller →
Conjurer, Gatekeeper and World Binder archived. SAS bonded slimes stay out
of this system entirely (locked).
